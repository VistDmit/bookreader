# Книжный помощник (bookreader)

Читает книги вслух живым голосом, переводит иностранные книги на русский и
показывает иллюстрации. Работает **на CPU, без видеокарты**: Ryzen 7 2700,
15 ГБ памяти — и этого хватает.

```
python run_bookreader.py web ~/книги/Довод.docx      # читалка в браузере
python run_bookreader.py read ~/книги/Арифурэта.fb2 # чтение вслух в терминале
python run_bookreader.py tui  ~/книги/Арифурэта.fb2 # терминальный интерфейс
```

## Что умеет

| | |
|---|---|
| **Читает вслух** | Silero TTS v5, пять голосов, автоударения и омографы, темп 0,6–2× |
| **Переводит** | NLLB-200 офлайн (600M или 1,3B), запасные онлайн-движки |
| **Показывает картинки** | иллюстрации к абзацам, обложка, панель сбоку |
| **Форматы** | FB2, EPUB, TXT, PDF, DOCX, а также книга внутри `.zip` |
| **Интерфейсы** | браузер и терминал, настройки общие и правятся в обоих |
| **Помнит** | где остановились, кэш озвучки и переводов в sqlite |

Поддерживаются книжные форматы с иллюстрациями (FB2, EPUB) и «бумажные»
(PDF, DOCX, TXT) — у них вёрстку и картинки восстановить нельзя, зато текст
и озвучка получаются в порядке.

## Установка

```bash
git clone https://github.com/VistDmit/bookreader.git
cd bookreader

python3 -m venv .venv && source .venv/bin/activate

# базовый набор: разбор книг, веб-читалка, самопроверки
pip install -e .

# голос (torch лучше ставить из индекса CPU — без видеокарты он не нужен)
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install -e ".[voice]"

# перевод
pip install -e ".[translate]"
```

Затем скачать модели (нужна сеть только один раз):

```bash
python run_bookreader.py models        # голос + переводчик, ~760 МБ
python run_bookreader.py doctor        # проверить, что всё на месте
```

## Команды

| команда | что делает |
|---|---|
| `web [книга]` | читалка в браузере на `http://127.0.0.1:8810` |
| `read книга` | чтение вслух в терминале (`--start`, `--paragraphs`, `--speed`) |
| `tui [книга]` | терминальный интерфейс: список книг, плеер, настройки |
| `info книга` | разбор: формат, язык, абзацы, картинки, время чтения |
| `translate "..."` | проверить перевод на своей фразе (`--source`, `--target`) |
| `translate-book книга` | перевести книгу целиком, с прогрессом |
| `voice test` | записать образец голоса в `state/cache/preview.wav` |
| `voice use silero v5_5_ru baya` | сменить голос |
| `voices` / `models` | какие голоса есть на машине; скачать модели |
| `doctor` | окружение, модели, звук, место, память |
| `verify [книга]` | открыть читалку в Chromium и проверить, что звук идёт |
| `recent` / `cache` | где остановились; что лежит в кэше |
| `config` | настройки (`--set ключ=значение`) |
| `test` | самопроверка без сети и моделей |

## Настройки

Одно окно на все параметры: **⚙ в шапке** читалки (или клавиша `s` / `m`) и
клавиша **m** в терминале. Значение сохраняется сразу в `state/config.json`
и действует в обоих интерфейсах.

Группы: **Голос** (движок, модель, голос, частоты, звуковая карта),
**Чтение** (темп, паузы, опережение, язык перевода), **Перевод**
(автоперевод, движок, модель), **Интерфейс** (шрифт, тема, порт).

Кнопки «Послушать голос» и «Проверить перевод» проверяют настройки, не
открывая книгу. Схема описана один раз в `bookreader/settings.py` — из неё
собираются оба интерфейса, поэтому они не расходятся.

## Модели

| | модель | размер | комментарий |
|---|---|---|---|
| Голос | Silero TTS `v5_5_ru` | 145 МБ | пять голосов, синтез вчетверо быстрее реального времени |
| Голос (запасной) | Piper `ru_RU-*-medium` | 60 МБ | легче и быстрее, но голос ровнее не выйдет |
| Перевод | NLLB-200 distilled 600M (CT2 int8) | 630 МБ | по умолчанию |
| Перевод | NLLB-200 distilled 1.3B (CT2 int8) | 1,3 ГБ | перевод лучше, скорость такая же |

Модели не входят в репозиторий и скачиваются командой `models`.

Переключить модель перевода:

```bash
python run_bookreader.py config --set nllb_repo=OpenNMT/nllb-200-distilled-1.3B-ct2-int8
```

## Как устроено

```
run_bookreader.py       тонкая обёртка
bookreader/
  launcher.py           перезапуск с -X gil=0 (см. грабли №1)
  cli.py                команды
  config.py             настройки: файл + переменные окружения
  settings.py           единая схема настроек для обоих интерфейсов
  books/                fb2, epub, txt, pdf, docx -> общая модель Block/Section
  langid.py             определение языка по служебным словам
  translate.py          NLLB через CTranslate2 + запасные онлайн-движки
  voice.py              Silero TTS v5 (основной) и piper (запасной)
  audio.py              WAV, тишина, склейка, передискретизация (без scipy)
  player.py             воспроизведение: очередь, пауза, темп
  reader.py             конвейер книга -> перевод -> озвучка
  server.py             HTTP + websocket
  web/index.html        страница читалки целиком в одном файле
  tui.py                терминальный интерфейс
  cdp.py                проверка страницы в браузере
  state.py              sqlite: история, позиция, кэш переводов и озвучки
  state/                модели, кэш, база, настройки (в git не попадает)
```

Поток чтения устроен так: книга разбирается один раз, затем абзацы
готовятся **впереди** текущего — сначала перевод, потом озвучка. Очередь
короткая (по умолчанию 3 абзаца), потому что перевод всей книги заранее
займёт часы, а читать можно сразу.

## Грабли, на которые уже наступили

1. **Импорт модуля без пометки «без GIL» включает GIL обратно.**
   `ctranslate2` и `lxml` ведут себя так: озвучка, перевод и веб
   встают друг другу. Поэтому лаунчер один раз перезапускает интерпретатор
   с `-X gil=0` — и запускать надо через `run_bookreader.py`.
2. **API CTranslate2 4.x другой.** Токены передаются строками, целевой
   язык — через `target_prefix=[["rus_Cyrl"]]`.
3. **Токенизатор NLLB не добавляет BOS/EOS** и пишет код языка как
   `eng_Latn` (без `>>`). Собирать вход вручную.
4. **Первый ответ `/api/audio/N` — 202**, а не 200: озвучка готовится в
   фоне, клиент обязан опрашивать.
5. **FB2 бывает и zip-архивом, и обычным XML**; книга может лежать внутри
   `.zip`. Имя файла ничего не гарантирует.
6. **В EPUB и PDF глава приходит одним абзацем** на десятки тысяч знаков —
   длинные блоки режутся на куски по 1200 знаков.
7. **Silero падает с пустым `ValueError` на разделителях** (`***`, `...`) —
   куски без букв и цифр отбрасываются до синтеза.
8. **Словарь блоков меняется из веба, пока его перебирает фоновый поток.**
   Перебор без замка убивал поток подготовки, и книга молчала.
9. **Корутину нельзя отдавать циклу событий из другого потока** через
   `call_soon_threadsafe` — нужен `asyncio.run_coroutine_threadsafe`.
10. **Публичные онлайн-переводчики отвечают 403** с домашней сети,
    `translate.googleapis.com` — 429. Рабочий запасной:
    `api.mymemory.translated.net` (словарный, лимит ~5000 слов в сутки).
11. **safetensors 0.8.0 не собирается под cp314t** — нужен `0.9.0rc1`.
12. **Долгий сервер не видит правок настроек из консоли**, если держать их
    только в памяти: `Config` перечитывает файл по mtime.
13. **В textual нельзя дублировать клавиши** — первое совпадение выигрывает.

## Ограничения

- Перевод NLLB-600M дословный («бездельничать» → «ничего не делать»).
  Модель 1,3B лучше, но тоже не переводчик-человек.
- Из PDF и DOCX не восстанавливается вёрстка: картинки, которые не
  привязаны к тексту, показываются в начале.
- Голос только русский. Книга на другом языке переводится на русский, а
  не читается на своём.
- Поддерживается free-threading сборка CPython 3.14 (и обычная 3.11+,
  но без выигрыша от отсутствия GIL).

## Разработка

```bash
python run_bookreader.py test      # 105 проверок без сети и моделей
python run_bookreader.py verify    # открыть читалку в Chromium и проверить звук
ruff check .                       # стиль (настройки в pyproject.toml)
```

CI (`.github/workflows/tests.yml`) ставит только базовый набор без torch и
CTranslate2 и прогоняет самопроверку на Python 3.12 и 3.13: этапы с моделями
пропускают себя сами, если моделей нет.
